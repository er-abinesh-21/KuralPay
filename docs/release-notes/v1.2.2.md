# KuralPay 1.2.2

You can now see updates happen.

## What's new

- **Update progress:** a notification shows the download with a progress bar, then the check and the install
- **Updated message:** after an update, KuralPay tells you the new version and that your payments, settings and sign-in are kept
- **Faster updates:** when you open KuralPay, a new version downloads straight away and installs as soon as you leave the app
- If an update can't finish, KuralPay tells you and tries again later

## Install

- Requires Android 12 or later.
- Already have KuralPay? Install over it. Your payments, settings and sign-in are kept. Do not uninstall first: uninstalling deletes the payment history stored on the phone.
