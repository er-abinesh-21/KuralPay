# KuralPay 1.2.1

A fix for 1.2.0.

## What's new

- **Fixed:** KuralPay 1.2.0 kept offering itself as an update. Check for updates now correctly says you're on the latest version
- Everything from 1.2.0: GPay Business payments, recovery of missed payments, no double counting of bank SMS, forwarding with names, and automatic updates

## Install

- Requires Android 12 or later.
- Already have KuralPay? Install over it. Your payments, settings and sign-in are kept. Do not uninstall first: uninstalling deletes the payment history stored on the phone.
